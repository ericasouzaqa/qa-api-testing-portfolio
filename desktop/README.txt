QA API TESTING PORTFOLIO — VERSÃO DESKTOP

1. Extraia o arquivo ZIP em uma pasta do Windows.
2. Abra a pasta extraída.
3. Dê duplo clique em QA-API-Testing-Portfolio.bat.
4. O arquivo index.html será aberto no navegador padrão.

O portfólio funciona offline porque o conteúdo principal é local e usa somente HTML, CSS e JavaScript. Não é necessário instalar Node.js, Cypress, Postman, banco de dados, backend ou qualquer serviço externo para ler o material.

Os exemplos de Postman, Cypress e APIs públicas são exercícios opcionais. Para executar requests reais, use Postman ou Cypress separadamente e confirme a disponibilidade e a documentação de cada serviço.
